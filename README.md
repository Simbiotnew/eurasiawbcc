# World Beauty Eurasia — сайт чемпионата

Одностраничный сайт международного онлайн-чемпионата и конференции World Beauty Eurasia 2027.
HTML, CSS и чистый JavaScript, без сборщиков и библиотек. 6 языков: EN, RU, DE, PL, IT, FR.

## Структура

```
wbc-eurasia/
├── index.html          — разметка страницы
├── style.css           — стили (mobile-first: сначала телефон, потом @media для планшета и десктопа)
├── script.js           — переключение языка, обратный отсчёт, мобильное меню, окно судьи
├── translations.js     — все тексты сайта на 6 языках
├── img/
│   ├── logo.jpg        — логотип в шапке
│   ├── favicon.png     — иконка вкладки
│   └── judges/         — фото судей 480×640
└── README.md
```

## Разделы страницы

Главный экран с обратным отсчётом до конца регистрации → Мероприятия и даты → Номинации →
Условия участия → Стоимость → Как зарегистрироваться → Зачем участвовать → Жюри → FAQ → Регистрация.

## Как вносить правки

**Тексты.** Все надписи лежат в `translations.js`. В HTML у элемента стоит ключ, например
`<h2 data-i18n="events.title"></h2>`, а текст для этого ключа есть в каждом из 6 языковых блоков.
Меняете текст во всех нужных языках, HTML не трогаете.

**Даты и цены.** Даты — в `translations.js` (ключи `events.*`, `steps.3.p`, `faq.*`).
Дата окончания регистрации для обратного отсчёта — в `script.js`: `const DEADLINE = new Date("2027-01-20T23:59:59")`.
Цены — прямо в `index.html`, раздел `id="pricing"`.

**Судьи.** Раздел `id="judges"` в `index.html`. У каждого судьи:
- `<button class="judge">` — карточка (фото, имя, страна, значок номинации);
- скрытые блоки `<div class="judge__bio" lang="..." hidden>` — регалии, по одному на каждый язык.
  Окно показывает блок на языке сайта, а если его нет — английский.

Чтобы добавить судью: скопируйте целиком `<li>…</li>` любого судьи, поменяйте фото, имя,
ключи `role.*` и `c.*` (номинация и страна) и тексты регалий. Фото положите в `img/judges/`,
пропорция 3:4 (например, 480×640).

**Новый язык.** Скопируйте блок `en` в `translations.js` и переведите, добавьте `<option>` в
переключатель в `index.html` и код языка в массив `SUPPORTED` в `script.js`.

## Как посмотреть локально

Откройте `index.html` в браузере. Все файлы и папка `img` должны лежать рядом, как в структуре выше.
